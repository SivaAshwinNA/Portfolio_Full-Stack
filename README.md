# Full Stack Personal Portfolio

A simple full-stack personal portfolio website built for the Thiranex Full Stack Development Internship Task.

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB Atlas
- CSS
- Git & GitHub

## Features

- Personal introduction
- Technical skills
- Project showcase
- Internship experience
- Contact form
- REST API
- MongoDB database integration
